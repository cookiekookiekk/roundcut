# RoundCut — 赛事集锦快速剪辑工具

把一条 5–10 分钟的完整赛事集锦，自动拆成一个个独立回合，你只负责挑哪些保留，最后拼成 1–2 分钟的新集锦。

## 在线使用

直接用浏览器打开 GitHub Pages 地址即可，无需安装。

## 核心特性

- **多模态切点检测**：画面（直方图差异 / SSIM / 帧差）+ 声音（频谱通量 / MFCC 距离 / 频谱差异 / 能量突变）融合打分，定位集锦中已存在的剪辑点
- **抗干扰**：击球声是 20–50ms 瞬态，通过中位滤波 + 前后窗对比与硬切区分开；导播的场内镜头切换（全场↔特写）不会被误判成回合边界
- **快速筛选**：键盘流操作（空格播放 / ←→ 切换 / Enter 保留 / Del 删除），顶部实时显示当前保留时长
- **人工纠错**：可调起止时间、合并相邻回合、手动加切点、删除错误切点
- **导出**：优先 FFmpeg stream copy 拼接，避免重编码；也支持浏览器内直接导出

## 隐私

纯前端单文件，视频全程在本机浏览器内处理，**不会上传到任何服务器**。

## 技术说明

单个 HTML 文件，CSS / JS / 图标全部内联，零外部依赖。
